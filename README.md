# 🚀 CompetitorPulse AI

An AI-powered competitor monitoring platform built with Python and Flask.

## 🌐 Live Demo

**Try the application:** https://competitorpulse-ai.onrender.com

## ✨ Features

* Monitor competitor websites.
* Discover new articles and blog posts.
* Extract article titles and descriptions.
* Analyze article keywords.
* Maintain a history of competitor scans.
* Configure email and Slack notifications.

## 🛠️ Tech Stack

* Python
* Flask
* SQLite
* BeautifulSoup
* Scikit-learn
* HTML and CSS

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/shreyasahani26/CompetitorPulse-AI.git
cd CompetitorPulse-AI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file and add the configuration required by the application. Never commit API keys, passwords, or other secrets.

### 5. Start the application

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
